# Security

This is a personal project, provided as is and without warranty (see `LICENSE`).

To report a security issue, please do not open a public issue. Use GitHub's private vulnerability reporting
(the repository's Security tab, "Report a vulnerability").

The repository holds no credentials. Deployment settings (the Pi's login and address) live in a git-ignored
`deploy/pi.env`, and the planner's own settings in a git-ignored `.env`; templates are `deploy/pi.env.example`
and `.env.example`.
